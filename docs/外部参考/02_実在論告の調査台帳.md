# 実在論告の調査台帳

確認日：2026-11-09。担当：Codex。依頼：木村忠太被告事件の論告準備のため、状況が似た実事件の論告を広く探し、全文を優先して知識として保存する。

本書は**25事件・資料候補の所在と確認範囲**を記録する。25本の論告全文を入手・読了したという意味ではない。同一事件の分割記事・転載・複数審級を別事件として水増ししない。[読み取った知識](03_論告から得た知識と本件への使い方.md)、[作業知識索引](../知識/作業知識索引.md)も参照。

## 全文優先の調査結果

- **無料公開の論告原稿PDFを取得できたのは、今回の調査では東電刑事裁判の1事件・2分冊（RC20）**。殺人の犯人性を争う本件との類似性は低い。全体の所在・表紙・目次・分冊境界・末尾等を確認したもので、全ページ読了ではない。
- **本件と似ていて長く読めるのは明王台、江戸川区教諭、木嶋、舞鶴、袴田等**。いずれも報道・傍聴記・引用であり、論告原稿全文の取得は確認できていない。
- 帝銀・松川・武生には、論告をまとめた冊子の書誌と所蔵先がある（RC21〜23）。本文未読。冊子があることと、誰でも無料で全文を開けることを区別する。
- 練馬・橋本等は有料の傍聴記候補。見出しや公開部分だけから、購入後の全文性・正確性を保証しない。購入・登録はしていない。

### 完全性と読解状態の凡例

| 記号 | 意味 |
|---|---|
| A | 論告原稿の全体を収める公開ファイルを取得。全ページの欠落検査・全文読了とは別 |
| B | 論告原稿の一部または論告からの引用。原稿全体は未取得 |
| C | 法廷報道・傍聴再現。長文でも逐語性・無省略を保証しない |
| D | 報道要旨・短い引用。記事が全文表示でも論告全文ではない |
| E | 有料・会員制の候補。公開部分のみ確認、制限後は未読 |
| F | 書誌・所蔵等の所在確認のみ。論告本文未読 |

「類似性：高／中／低」は今回のAIによる比較上の目安であり、証拠力・事件の結末・模範としての評価ではない。各欄の学びは本件への**検討案**であって、他事件の検察主張を正しい認定として採用したものではない。

- 限界：別事件の鑑定精度・刃長・傷の深さを本件へ移さない。量刑・否認への非難は本企画の原稿の手本にしない。

## 調査・保存・再利用の方法

1. 「論告全文」「論告要旨」「論告本文」「法廷ライブ」「論告求刑」の横断検索に、血痕・DNA・自転車・映像・嫉妬・犯人性の事件名を組み合わせた。報道元、研究機関、弁護側資料、図書館書誌にも範囲を広げた。
2. 全文原稿を優先しつつ、類似事件の有用な要旨・未取得の所在も残した。検索結果でだけ確認できたものは明記し、アクセス失敗を消さない。
3. 閲覧用に取得した第三者記事・PDFは一時領域だけに置く。公開リポジトリにはリンク、確認範囲、自分の言葉による短い要約・比較を保存し、全文転載や独自の公開ミラーは作らない。
4. 今後の優先順はRC02→RC01→RC03→RC04→RC05。原稿全体の構成を見たいときはRC20。RC21〜24は現物取得後に確認範囲を更新する。
5. 他事件の主張の強さや有罪・無罪の結果から、本件の結論を自動的に導かない。原稿化では本件の原資料・実際の回答・正本ノートへ戻る。
