## 推論の説明で取り入れること

**一つの段落で、証拠が示すことと推論の理由を両方書く。** 明王台事件の掲載文（RC01）は、DNAの説明と凶器・所持品等の説明を項目に分ける。参考にするのは根拠の分節であり、その事件の鑑定結果や結論ではない。本件でも「眼鏡は木村の物」だけで止めず、それがどの事実を支え、事件時の行動をいうには何が加わる必要があるかを示す。

**相手の説明を、具体的な根拠を添えて検討する。** 木嶋事件の分割報道（RC03）では、鍵の捜索や別の場所への移動という反論について地図・捜索状況・証言を示して応答する。検察官が不合理と述べたこと自体を結論の根拠にしない。本件の昼の落下説に対しても、清掃者の確信だけでなく、B地点の観察範囲・暗さ・車両・急ぎなど実際に確認できた条件を扱う。

**証拠全体の評価では、異なる証拠が同じ未証明の前提に依存していないかを確認する。** 本件のR04はR03を前提にする。自転車の事件時使用が未証明のまま「自転車も映像も別々に犯人を示す」と言えば、同じ仮説を二度足すことになる。逆に、一つの事情に別の説明があるだけで全証拠を無視するのでもなく、同じ説明で各事情をどの程度説明できるかを検討する。これは今回の分析上の提案であり、他事件の語句を引用した法的基準ではない。

## 話し方・構成で取り入れること

- 冒頭で主争点と検察の結論を示し、その後に説明する順を短く予告する。RC01・RC03の掲載文が参考。
- 「第一に」「次に」「ここまでから」という案内を付け、一つの段落で複数の論点を飛び回らない。RC10の公開部分が参考。
- 事実の説明と評価を続けて話し、聞き手に推論の空白を埋めさせない。根拠ノート・号証・教材ページは原稿の作成用対応表へ残す。
- 相手の反論を正確に示してから、自分の評価と理由を述べる。反論を実際より弱くして処理しない。
- 最後の総合評価は、既に説明した根拠とその組合せの意味を短く確認する。最後に新しい証拠・事実・筋書きを追加しない。

以上は参考資料を踏まえた今回の編集方針で、唯一の正しい論告の型と主張するものではない。法的な位置付けは、[裁判所の弁論手続の説明](https://www.courts.go.jp/saiban/syurui/syurui_keizi/keizi_02_03/index.html)、[大阪地裁の論告の説明](https://www.courts.go.jp/osaka/kengaku/virtual_tour/13th/index.html)、[検察庁の公判Q&A](https://www.kensatsu.go.jp/qa/qa3.htm)を別に参照する。

## 模倣しないこと・本件に移せないもの

| 外部資料で見かける要素 | 本件での扱い |
|---|---|
| 強い形容詞、被告人の表情や生活態度への非難 | 形容詞の強さで犯人性の証明を補わない。少年時の暴力歴を性格推論の近道にしない |
| 否認・反省の欠如を中心とする量刑論 | 本企画は求刑・量刑意見なし。否認を独立の有罪証拠に置き換えない |
| 他事件の医学的数値やDNAの出現頻度 | 本件の鑑定・教材にない数字を補わない |
| 物が本人の物なら犯行時に残したという短絡 | 所有・遺留時期・移動・付着機序・本人の行為を分ける |
| 映像・移動時間の精密な分析 | 本件にない速度、厳密な距離、時刻の確定を持ち込まない |
| 被告人が別の犯人や移動者を特定できないこと | 弁護側に真犯人の特定や無実の証明を要求しない |
| 全文無料・全文表示という記事見出し | 論告原稿の省略なし全文かを別途確認する |
| 長い論告、求刑どおりの判決、PR・CIの成功 | 法的推論の十分性や人の採用レビューとは別 |

## 原稿作成へ進むときの手順

1. ユーザーが書こうとしている段落の主張を一文にし、対応する本件の正本ノート、号証、教材ページ、最新の法廷回答の根拠を示す。
2. その主張に対する最も強い反論と、前提を外した場合の到達点を確認する。外部事件の型を先に当てはめて証拠を選ばない。
3. [実施ルール](../08_実施ルール.md)の12分・求刑なしに合わせて構成する。現段階では完成原稿・各段落の文言を確定していない。
4. 原稿化前に `python 作成用/reasoning_graph.py --gate T00` を実行する。保留は保留として報告し、人の確認がない主張を確認済みとして本文化しない。
5. 仮置き案を求められたときは、仮定・使用条件と差替え箇所を明示する。公開された実事件の表現を長く流用せず、自分たちの証拠に即した文章にする。

- 他事件の最新の裁判経過を全件追跡した資料ではない。過去の論告を、現在の有罪認定が存在することの根拠に使わない。
