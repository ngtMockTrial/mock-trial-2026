# 論告の書き方――本件のための人間向け手引き

作成・確認：2026-11-09。対象は木村忠太・岸井新之助の模擬事件。**書き方の手引きと練習例であり、完成論告や、人が採用した事実認定ではありません。** 例文は今回作成したものです。

論告では、**「この証拠から、この事実が分かる。そこから、この理由で、被告人が犯人だと判断できる。弁護側のこの説明を考えても、その判断は変わらない」**という道筋を、聞き手がたどれるように説明します。本件では、とりわけ「木村の物が現場にある」から「木村が刺した」へ進む理由が大切です。

初めて書く人は、次の順で進めてください。

1. 「まず守る条件」を確認する。
2. 「主張と証拠の表」を埋める。
3. 「一段落の型」で、眼鏡について一段落だけ書く。
4. 「全体の構成」へ並べ、反論と総合評価を補う。
5. 音読して時間を測り、末尾のチェックリストで最終確認する。

根拠の詳しい確認記録は[外部参考04](外部参考/04_論告の書き方の出典と確認記録.md)。公式資料の説明、本件の資料記載、今回の編集上の提案を区別しています。配分・段落の型・例文は、公式の必須書式ではなく本プロジェクト用の提案です。

## 文章より先に、主張と証拠の表を作る

いきなり12分の文章を書くと、印象的な事情を並べただけになりがちです。最初に「何を認めてもらう段落か」を一文で書き、その根拠と限界を埋めます。

用語は、次のように考えれば十分です。

| 用語・ノート | 普通の言い方 | 本件の例 |
|---|---|---|
| 証拠 E | 判断の材料 | 甲1の眼鏡に関する報告 |
| 間接事実 F | その材料から分かる、結論の手前の事実 | 現場で発見された眼鏡と木村との結び付き |
| 推認 R | その事実から、さらに何を考えられるか。その理由 | 血液・発見場所等を併せて事件時の在場を考える |
| 要証事実 T | 最終的に証明したいこと | 木村が刺突行為者であること |
| 反論 D・確認 Q | 違う説明と、まだ確かめる必要がある点 | 先に落ちた物への後の付着、B地点の視認条件 |

これは配布写真P11の考え方を本件向けに言い換えたものです。[原画像IMG_4405.JPG](../00_元資料/追加写真/IMG_4405.JPG)を確認できます。映像なら常に直接証拠、DNAなら直ちに犯人の証明、という分類ではありません。**何を証明するために使うか**で考えます。

## 本件では、眼鏡から犯人性までを分けて考える

本件の中心を一文で置くなら、**「木村の眼鏡に岸井の血液があり、現場で見つかったという組合せが、事件時の木村の行動をどこまで示すか」**です。これは検討する問いであり、結論が既に証明されたという意味ではありません。［[双方の立証構造](13_双方の立証構造と評価.md)、[R02](../検討/ノート/R02.md)］

| 段階 | 確認・説明すること | 進み過ぎる例 |
|---|---|---|
| ①誰の物か | 自身の遺失物との説明、指紋・皮膚片DNA型、購入記録等。甲1 p.4、E02・F01 | 「同型品を買ったから、その人以外の物ではあり得ない」 |
| ②何が付いているか | 眼鏡の血痕のDNA型が岸井と一致したという報告。甲1 p.4、E03・F02 | 「刺した瞬間に飛び散った血液だ」 |
| ③いつB地点へ来たか | 発見時刻と、清掃時の具体的な観察。甲1 p.3、甲3 p.21〜22は留保。実際の回答を確認。R01・D01 | 「見なかったと言うので、その場に絶対なかった」 |
| ④事件時に誰が着用・所持したか | ①〜③や他の事情の組合せが、事前紛失・後の付着等と比べて何を示すか。R02・D02・D03 | 「持ち主なら事件時にも掛けていた」 |
| ⑤誰が刺したか | 在場や近接から行為者の特定へ進む理由を、他の証拠も含め説明。T01・D09 | 「その場にいたなら刺した」 |

各段階に必ず別個の直接証拠が必要、という意味ではありません。間接事実の組合せで考える場合も、どの条件を使って結論へ進んだかを明らかにします。[最高裁判例等の既存整理](外部参考/01_刑事事実認定の公式資料.md)のEXT01・02も参照してください。

## 一段落は、一つの問いに答える

書く前の整理は「証拠→事実→推論→結論」。聞いてもらう文章では、最初に短く論点・小結論を示し、その後に根拠を説明すると、何の話か伝わります。

**問い・小結論 → 証拠と分かる事実 → なぜそう考えるか → 有力な反論 → 証拠に基づく応答 → この段落の到達点**を一つの型として使ってください。反論が長い場合は次の段落に分けます。

### 例1：所有について、言える範囲で書く

書き直す前の例：

> 眼鏡から木村のDNAと指紋が出たので、木村が犯人であることは明らかです。

これでは「所有」と「犯行」を一度につないでいます。まず、所有という小さい問いに答えます。

> まず、現場で発見された眼鏡と木村との結び付きです。甲1の4ページには、木村がこの眼鏡を自身の遺失物と認めたこと、付着した指紋と皮膚片のDNA型が木村と一致したことが記載されています。この組合せは、この眼鏡が木村の物であることを支えます。ただし、これだけで、事件のときに木村が掛けていたことまで決まるわけではありません。そこで次に、岸井の血液と発見場所、眼鏡がそこへ来た時期を検討します。

**今回作成した練習例・人の採用前**。根拠は[甲1 教材p.4](../00_元資料/教材集.pdf#page=6)、[E02](../検討/ノート/E02.md)・[F01](../検討/ノート/F01.md)。所有の説明を何度も繰り返さず、次に争う段階へ進む例です。

### 例2：清掃の回答で、書く文を変える

準備段階では「大滝はB地点を確実に確認した」と確定して書きません。実際の回答とその信用性に応じて選ぶ文を用意します。

| 実際の証言・記録の状態 | 書き方の分岐例 |
|---|---|
| 当日のBをどう見たか、見える条件、確認時間等が具体的に支えられた | 「大滝は〔実際の回答〕と述べています。〔他の証拠〕と合わせれば、Bに眼鏡があれば気付く条件だったと考えられます。このため、清掃時にはBに眼鏡がなかったとの推認を支えます」。角括弧は実記録で埋め、見落としの反論にも応答する |
| 通常の掃除の仕方だけで、当日のB視認は曖昧 | 当日の不在を断定する文を削る。「通常の清掃をしたこと」から言える範囲にとどめ、残る眼鏡・血液等で評価し直す |
| Bが車の影などで確認できなかったとの回答 | 確認できなかった範囲に不在推認を使わない。どの段落・総合評価を変えるかも記録する |
| 実際の回答記録がない／確認できない | 甲3の記載を証言に読み替えず、条件付きの準備文として保存する |

第一の分岐でも、到達点はまず**清掃時のB不在**です。「清掃後にBへ来た」ことから「20時30分に木村が落とした」「木村が刺した」へは、さらに理由が要ります。地面に先にあった物への後の付着や、別の場所からの移動も、それぞれの根拠と限界を検討します。［[R01](../検討/ノート/R01.md)・[D01](../検討/ノート/D01.md)・[D03](../検討/ノート/D03.md)、甲1 p.3〜6・11〜14、甲3 p.21〜22は留保］

## 反論には、相手が本当に争う点で答える

弁護側の主張を弱く作り直して否定すると、核心が残ります。例えば「眼鏡は木村の物ではない」という反論だけに答えても、「木村の物だが、先に落ちていた」という反論への回答にはなりません。

次の四つをメモし、必要な部分を本文へ入れます。

1. **相手の説明**：相手の主張・法廷回答・こちらの想定反論を区別して、最も有力な形で書く。
2. **根拠**：その説明が本件のどの事情に支えられるのかを書く。単に想像できるだけの筋とも分ける。
3. **応答**：こちらのどの証拠が、その説明と両立しにくいのか、理由まで示す。
4. **残る疑問**：答え切れていない点と、それが最終結論に与える影響を点検する。

| 論点 | 弁護側の有力な指摘 | 検察側が説明すべきこと |
|---|---|---|
| 眼鏡 | 所有と、事件時の着用・血液付着は別 | 被害者血液・Bでの発見・使用可能な時期資料を組み合わせ、事件時の本人の行動へどう結び付くか |
| 清掃 | 急いでいた、暗さや死角がある、当日の記憶が曖昧 | 実際に観察した範囲と発見可能性。不利益な回答を無視せず、使えない範囲を除く |
| 自転車 | 共用なので木村の指紋は普段の使用で説明できる | 被害者血液がある意味と、血液付着時の利用者を木村とする理由を分ける。指紋と血液が同じ時に付いたとは決めない |
| 映像 | 顔が分からず、車両も特定できない | 時刻・方向・外見から言える範囲。人物の同一性と車両の同一性を別々に示す |
| LINE | 怒りはあっても実行した証明にはならない | 怒りと被害者の所在認識が他の証拠に何を加えるか。動機だけで犯人性や殺意を決めない |
| 被告人の説明 | 記憶違い・推測もあり得る | 問われた事項、実際の答え、客観証拠との具体的な食い違い、その食い違いが重要な理由 |

本件の根拠・双方の検討は[証拠表](03_証拠と利用範囲.md)、[双方の立証構造](13_双方の立証構造と評価.md)、[質問の回答分岐](14_尋問の優先順位と回答分岐.md)へ戻ります。被告人の説明に疑問があっても、そのことだけで検察側の不足を埋めません。黙秘したことを有罪理由にせず、実際に述べた説明を評価するときも、その箇所と理由を示します。［[裁判所Q&A](https://www.courts.go.jp/saiban/qa/qa_keizi/index.html)「黙秘権」「立証責任」］

## 「総合すると」の後に、組み合わせる理由を書く

総合評価では、証拠の名前をもう一度並べるだけでは足りません。**それぞれが何を補い、全部を踏まえても、木村が犯人ではないという合理的な疑いが残るか**を説明します。

| 材料 | 加え得る意味 | 埋められない部分・注意 |
|---|---|---|
| 木村の眼鏡＋岸井血液＋B発見 | 木村の私物と被害者・現場との具体的な接点 | 事件時着用・付着経緯・行為者は追加の推論 |
| 清掃の証言 | 支えられた範囲で、Bに来た時期を絞る材料 | 未獲得・曖昧な回答では時期を絞れない。清掃後という幅だけで犯行時刻にならない |
| 共用自転車の血液等 | 眼鏡とは別の物・発見場所での接点 | 利用できる人が複数いる。使用者・時期の特定が必要 |
| 映像 | 場所・方向・時刻の整合性の検討 | 人物・車両の特定を仮定して、その仮定を映像で証明し直す循環にしない |
| LINE | 対象者への怒り、駐車場で見かけるとの認識 | その場所で実行したことの代用にならない |

［甲1 教材p.3〜6、甲2 p.19、乙1 p.25。清掃説明は甲3 p.21〜22・留保で、実際の回答を別途確認。[R02](../検討/ノート/R02.md)・[R03](../検討/ノート/R03.md)・[R04](../検討/ノート/R04.md)・[T01](../検討/ノート/T01.md)・[D09](../検討/ノート/D09.md)］

編集用には、次の空欄を埋めてみます。

> 〔事実A〕は、〔結論への意味〕を示します。ただし、これだけでは〔限界〕が残ります。そこで〔事実B〕を合わせると、〔具体的に補う点〕が分かります。弁護側の〔実際の主張／想定する別説明〕については、〔証拠〕が〔理由〕の点で問題になります。なお〔残る疑問〕があり、これを含めて〔どこまで主張できるか〕を判断します。

同じ眼鏡の指紋、皮膚片DNA型、購入記録は、所有を支える事情です。それを三つの独立した犯行証拠に数え直したり、写真・報告書・図解に同じ情報があるから証拠が増えたと扱ったりしません。また、弱い事情も組合せで意味を持つことはありますが、**数が多いから有罪、検察説の方が少しもっともらしいから有罪**とはいえません。数字の点数・有罪確率にも換算しません。［[検討を深める方法](17_検討の仕組みの評価と深め方.md)、[外部参考01のEXT01・02](外部参考/01_刑事事実認定の公式資料.md)］

## 全体を、判断しやすい順に並べる

本件では、次の構成から始めると書きやすくなります。順序は提案で、法廷で重要になった点に応じて変えます。

| 順 | 書く内容 | 読み手に答える問い |
|---|---|---|
| 1 冒頭 | 氏名、検察側の結論、主争点、説明する順序 | これから何を判断してほしいのか |
| 2 前提 | 死亡・死因などを必要な範囲で短く | どのような事件が起きたのか |
| 3 犯人性の中心 | 眼鏡の所有・血液・場所、清掃による時期の評価。各所で反論に応答 | なぜ木村の事件時の行動と結び付くのか |
| 4 補助事情 | 自転車・映像・LINE。それぞれの限界も示す | 中心の説明に何が加わるのか |
| 5 犯人性の総合評価 | 有力な別説明を含めた組合せの評価 | 在場から刺突行為者の特定へ進めるか |
| 6 因果関係・殺意・法律 | 刺創と死因、部位・複数性等による殺意の評価、起訴された殺人罪との対応 | 行為・死亡・殺意をどの根拠で論じるか |
| 7 結び | 核心の理由を短く再提示し、証明できた範囲に沿う結論、終了を明示 | 最後に覚えてほしい判断理由は何か |

時系列は、出来事の位置を理解するために必要なところで使います。別れから逮捕までを同じ詳しさで再話すると、肝心の「なぜ犯人といえるか」が埋もれます。甲1、甲2、乙1の順に資料を読み直す構成にもする必要はありません。

冒頭の練習例は「検察官役の〔氏名〕です。本件の中心は、岸井を刺したのが木村かどうかです。まず現場の眼鏡と血液、次に〔実際に使う補助事情〕、最後に証拠全体の意味を説明します」。有罪との結論を述べる場合も、**検察側の意見として**述べ、その後の本文で理由を示します。

結びは「〔中心となる事実の組合せ〕から、〔残る有力な反論への応答〕を踏まえても、〔人が確認した結論〕と考えます。以上です」という枠で作れます。初めて出す証拠や未説明の主張を結びに足さず、刑期を求める文も付けません。

### 殺意・因果関係は、犯人性と混ぜない

甲1教材p.3には、左胸部2か所、右上腹部1か所、両腕複数か所、右大腿部1か所の刺創痕、これらの傷に基づく出血性ショックという死因、凶器未発見の記載があります。因果関係はこの死因の報告とのつながりを説明します。殺意は、胸腹部を含む部位や傷の複数性がどのような行為・認識を示すかを検討し、分からない経緯等も踏まえて理由を書きます。［[E01](../検討/ノート/E01.md)・[R05](../検討/ノート/R05.md)・[R06](../検討/ノート/R06.md)・[D07](../検討/ノート/D07.md)］

**死んだので殺意があった、怒っていたので殺意があった、殺意のある犯行なので木村がした**という置換はしません。資料にない傷の深さ・刺突順序・刃長・力の強さを足さず、両腕の傷を専門鑑定上の防御創と断定しません。刺突行為者の殺意を論じることと、その行為者が木村だと証明することを分けます。起訴罪名・罰条の確認先は教材p.1。現在の刑罰の種類や量刑相場は、本手引きの調査対象にしていません。

## 聞いて分かる日本語に直す

聞き手は、長い文の途中へ読み戻れません。一文で一つのことを述べ、人物・場所・時刻が変わるところでは名前を入れ直します。これは本プロジェクトの編集上の提案です。

| 書きがちな表現 | 直し方 |
|---|---|
| 「以上の諸事情を総合考慮すると明白である」 | 何と何を合わせ、何が分かるのかを一文ずつ書く |
| 「このことから」「それ」「同人」が続く | 「眼鏡の発見場所から」「木村は」など、指す対象を言う |
| 「極めて不自然で信用できない」だけ | 「〔回答〕は、甲1の〔具体的記載〕と〔どの点で〕合わない」と説明する |
| 「18時には眼鏡はなかったと考えられるので犯人である」 | B視認の根拠、時期の推認、着用・行為者の推認を分ける |
| 長いLINEを一括朗読する | 怒り・対象・所在認識など、論点に関係する箇所を正確に選ぶ。前後で意味を変えない |
| 「犯行の2分後の逃走映像」 | 20時30分は起訴状上の時刻。独立した根拠を示せなければ、「20時32分頃の走行映像」から説明する |
| 「被告人の自転車」 | 所有を確定する表現を避け、「木村も普段使う共用自転車」と、根拠のある範囲で呼ぶ |

編集用原稿には出典と未確認条件を残し、読み上げ箇所・間・資料提示箇所を分かるようにします。提示物を使うなら、「どこを見てほしいか」「そこから何が分かるか」を声でも説明します。提示の操作時間も音読計測に入れます。内部ノートIDや編集メモは、読み上げる本文から区別してください。

## 12分へ収める

次は**練習用の配分案**です。企画の指定は12分という上限で、この内訳は指定されていません。清掃が争いの中心になったら、その部分を増やして他を削ります。

| 経過時間 | 内容 | 時間 |
|---|---|---|
| 0:00〜0:45 | 氏名・結論・争点と順序 | 45秒 |
| 0:45〜1:15 | 死亡等の前提 | 30秒 |
| 1:15〜5:00 | 眼鏡・血液・清掃、反論への応答 | 3分45秒 |
| 5:00〜6:45 | 自転車・映像と限界 | 1分45秒 |
| 6:45〜7:30 | LINEの意味と限界 | 45秒 |
| 7:30〜9:30 | 犯人性の総合評価と有力な別説明 | 2分 |
| 9:30〜10:30 | 因果関係・殺意・法律との対応 | 1分 |
| 10:30〜11:15 | 核心の理由と結論 | 45秒 |
| 11:15〜12:00 | 間・言い直し・提示等の余裕 | 45秒 |

「12分なら必ず何文字」という固定値は置きません。発表者が実際の速度で読み、段落ごとの時間を記録します。長いときは、同じ所有の根拠の繰返し、長い経緯説明、争点に結び付かない形容詞から削ります。**反論への応答と、証拠から結論へ進む理由を先に削らない**ようにします。

聞く人には、原稿を見ずに「中心の問い」「検察の主な理由」「弁護側の疑問への回答」を言い返してもらいます。言い返せなかった部分は、声量だけでなく説明の順と接続を直してください。

## 実演後20分で直すために、事前に分岐を用意する

これは**出場メンバーが、許可された手元資料で行う作業の提案**です。試合中に外部AIや出場メンバー以外へ相談する手順ではありません。通信・助言の制限は[実施ルール](08_実施ルール.md)に従います。

| 検討の目安 | 行うこと |
|---|---|
| 最初の5分 | 実際の採否・質問と回答・訂正箇所を共有。記憶と記録、答えたことと推測を分ける |
| 次の5分 | 清掃・紛失・在宅等について、どの前提が支えられ／崩れたかを段落表に反映 |
| 次の5分 | 使えない文を削除・弱める。中心段落だけでなく総合評価・結びも直す |
| 最後の5分 | 分担、つながり、終了時刻、求刑が混入していないかを確認。修正した重要箇所を声に出す |

全部を書き直すより、「この回答ならこの段落を使う」「この回答ならこの文を削る」という分岐を準備しておきます。ただし実際の回答が選択肢のどれとも違うなら、無理に当てはめません。

## 書き終えたら確認すること

- [ ] 一番大きい問いが犯人性になり、冒頭の予告と本文の順が合っている。
- [ ] 各段落に、主張・正式号証／法廷記録・該当箇所・ノートIDの対応がある。
- [ ] 「資料記載」「当事者主張」「実際の供述」「推論」「未確認」を混ぜていない。
- [ ] 甲3・乙2にだけある内容を、実際の証言として読み替えていない。新たな回答があるときは、その記録を参照した。
- [ ] 所有→事件時着用→在場→刺突の間を飛ばしていない。
- [ ] 眼鏡・鑑定の重複計上、自転車と映像の循環、起訴状の時刻の証拠化がない。
- [ ] 相手の最も強い説明を正確に扱い、証拠と理由で応答した。答え切れない疑問を隠していない。
- [ ] 怒り・少年時の暴力歴・逮捕起訴・黙秘・真犯人を挙げられないことを、有罪の近道にしていない。
- [ ] 刺創・因果関係・殺意と、木村が行為者かという問いを分けた。資料にない寸法等を足していない。
- [ ] 図解・外部事件・AIの説明を本件の証拠に加えていない。
- [ ] 求刑・量刑意見がなく、音読と提示を含め12分以内に収まる。
- [ ] 人が段落表を確認し、保留と修正条件を把握した。人のreviewをAIが上書きしていない。

AIが実際の原稿化を担当する場合は、先に段落表を示し、人が確認した主張を本文化します。未確定の仮置き案を依頼された場合は、未確認箇所と条件を明示します。`python 作成用/reasoning_graph.py --gate T00` と必要な枝のゲートを確認し、終了コード2の保留を隠しません。ゲートやCIの通過は、法的な十分性や人の採用判断を保証しません。
