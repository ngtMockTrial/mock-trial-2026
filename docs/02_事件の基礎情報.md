# 事件の基礎情報

## 起訴内容と主争点

検察側は、木村忠太が2025年12月26日20時30分頃、高知市五哲町5-31の月極駐車場「パークon it Hey！」敷地内又はその周辺で、岸井新之助に殺意をもって刃物で刺突し、同日21時55分に死亡させたと主張しています。罪名・罰条は殺人、刑法199条と記載されています。これは**起訴状の主張**であり、木村が行為者だという結論を起訴状自体で証明するものではありません。［教材p.1］

教材の進行例が示す主争点は「木村が岸井を殺害した犯人か」という犯人性です。［教材p.37・42］

## 原文の不整合・解釈の注意

1. 乙2 p.29の問いには「12月27日、駐車場の敷地内に入っていないか」、映像否定理由の答えにも「12月27日、酒に酔っており」とあります。事件当日は26日ですが、原文を26日に置き換えません。質問対象日・供述の趣旨を確認する事項です。
2. 弁護人冒頭陳述p.34は犯行時刻に自宅で寝ていたと主張。一方、乙2 p.28は夕方に起き、21時頃再び就寝したという記載です。20時30分に寝ていたのか、在宅だが起きていたのかを一括りにしません。
3. 甲1の昼夜ほの暗いという一般記述と、甲3の清掃時に視界は悪くなかったという説明は、対象時刻・場所・観察対象を確認して比較します。直ちに完全な矛盾とも一致とも判断しません。
