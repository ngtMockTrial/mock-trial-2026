# Obsidian標準グラフの使い方

2026-10-21再構築。**標準のグラフビューをExtended Graph 2.7.6で拡張**しています。ユーザーの参考画像に合わせ、関係に応じて自然に集まる物理配置です。点を列や段へ固定していません。

## 開き方

左のブックマーク →「模擬裁判・構造グラフ」→「01 論証の本筋」。証拠・事実命題・推認・要証事実・反論の34点が表示されます。確認・尋問準備まで読む場合は「02 詳細・準備と確認を含む」（43点）へ切り替えます。

CLIは `obsidian command id=graph:open`。右側のExtended Graphの切替が有効なら、個別サイズと形が反映されます。拡張の状態は「模擬裁判｜論証の本筋」。

## 目標・重要度・分類

| 表示 | 意味 |
|---|---|
| 最大の丸 T00 | 「被告人は有罪である」。検察側の最終立証目標・未認定 |
| 大きなT01・D09 | 主争点の犯人性と、その総合反論を表示上強調 |
| 青・赤・灰 | 検察・弁護・共通。配置位置ではなく色で立場を識別 |
| 四角 | 証拠 |
| 通常の丸 | 間接事実として検討する事実命題 |
| ひし形・三角形 | 推認・反論 |
| 六角形・五角形・八角形 | 要証事実・確認課題・準備資料または供述候補 |
| ⚠付きの名前 | 採否留保・未獲得・未確認の前提への依存。ノートに状態の詳細を記載 |

重要度5はT00だけ。4はT01・D09、3は他の要証事実・推認・反論、2は資料・事実命題等が初期値です。変更する属性は正本の`display_priority`。証拠力や有罪確率の数値ではありません。大きい点でも未確認の前提や反論が残ります。

## 見やすく使う

- ホイールで拡大縮小、背景をドラッグして移動します。
- 全体では線と塊を見て、名前は拡大・点へのマウス移動で読みます。全ラベルの常時表示による重なりを避けています。
- 青・赤の点を比較し、共通資料へどのようにつながるかを確認します。立場の異なる点が隣接しても属性は変わりません。
- 点をクリックして表示用ノートを開き、末尾の「編集用ノート」から正本へ戻ります。
- 「01 論証の本筋」で主張のつながりを見て、確認・準備が必要になったら「02 詳細・準備と確認を含む」へ切り替えます。
- 種類だけを見る場合、グラフの検索に `path:"検討/グラフ表示" [kind:証拠]` 等を指定できます。

矢印は「起点 → 対象」を直接結びます。関係名を表す58個の中間ノードは廃止しました。本筋は34点・41接続、詳細は43点・58接続です。線だけでは支持・反論・確認・準備・将来候補を区別できないので、点を開いた先の「このカードからの接続」「このカードに入る接続」の関係名を読んでください。反論の線を支持と解釈しないでください。

通常表示から省いたのはQ01〜Q05（確認課題）、E07・E09（留保調書の準備資料）、W01・W02（未獲得供述の候補）です。関連カードの「入る接続」からも開けます。本文の確認事項と、留保・未確認の前提への依存を示す⚠は残っています。見えないことを確認済みと扱わず、原稿化チェックも正本の全件を調べます。

## 更新

正本を保存 →「検討を更新.cmd」。CLIが有効でObsidianが起動中なら、更新後にアプリを再読込して表示とメタデータを揃えます。通常更新は正本本文、人のレビュー、Canvasの配置、グラフやブックマークの人の調整を上書きしません。

初期設定の作り直しを明示的に依頼された場合だけ `python 作成用/setup_extended_graph.py` を使います。この処理は生成した状態の設定を再設定し、その状態のピンを解除します。通常更新では使いません。

原稿化チェックは表示用ノートを根拠に数えず、正本だけを参照します。準備資料と将来候補を現在の支持と扱わないでください。
