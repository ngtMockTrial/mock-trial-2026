# 実施ルール

出典：S02 [フォローアップ企画ルールブック](../00_元資料/ルールブック.pdf)。全4ページを目視確認した要約です。開催情報は配布資料の記載であり、最新の開催状況を外部確認したものではありません。教材の一般進行例より、この企画の具体的な規定を優先して準備します。

## 企画と担当

ルールブックp.1では、2026年11月29日（日）12:30集合、京都弁護士会館地下大ホールに集合後、京都地方裁判所へ移動するとされています。参加校は長田高校が検察、関西大倉高校が弁護と記載されています。現在の作業フォルダ名だけでユーザーの担当を確定せず、両側の分析を保持します。

## 時間と準備範囲

| 項目 | 本企画の記載 | 出典 |
|---|---|---|
| 模擬裁判の実演 | 弁護士による冒頭手続から尋問までの実演 | p.1 |
| 参加者の主な発表 | 実演を踏まえて論告・弁論を修正し、発表 | p.1〜2 |
| 論告・弁論の再検討 | 20分 | p.2の時間表 |
| 検察官の論告 | 12分 | p.2の時間表 |
| 弁護人の弁論 | 12分 | p.2の時間表 |
| 事前準備 | 争点・主張立証方針・論告弁論を準備。必要なら追加尋問を検討・提出 | p.2 準備① |
| 証人・被告人の供述 | 配布教材から合理的に導かれる範囲 | p.2 準備④ |
| 求刑・量刑意見 | 述べない。ただし情状に言及することは禁止されていない | p.2 法廷での活動③ |

追加尋問は「あれば」の検討・提出です。本企画で選手が通常大会と同じ尋問時間を必ず持つとは記載されていないため、必要なら主催者の案内を確認します。

## 準備段階と試合中

事前準備では支援弁護士の助言を受けながら進めるとされています。一方、試合中は提出した出場メンバー以外との会話や助言を受けることは禁止です。両者を混同しません。［p.2 準備①、活動⑥］

論告・弁論は証拠に基づいて行い、時間を守り、発言前に氏名を名乗ります。発表中は法廷の柵の外に出られず、外部との接触も禁止です。［p.2 活動②〜⑦］

## 持込み・提示

- PC・タブレットは台数制限なく持込み可。裁判所の電源は使用不可。試合中の通信機能による外部通信は禁止。法廷柵内でのスマートフォン使用も禁止。［p.2〜3 活動⑨］
- 論告・弁論の要旨を記載した紙を審査員へ交付可能。会場にホワイトボード設置予定で使用可能。［p.3 活動⑩］
- 法廷内の飲食は原則禁止。ただし糖分摂取・体調管理等の必要がある場合は個別相談。［p.2 活動①］
- 裁判所内への刃物やスプレー缶等の危険物の持込みに制約あり。［p.3 その他④］

## 撮影

法廷内は撮影可、法廷外は撮影禁止との記載。敷地内駐車場等からの地裁建物撮影も禁止とされ、建物は敷地外から撮影するよう案内されています。動画用三脚は自校の試合中のみ、写真用三脚は禁止、フラッシュは禁止、シャッター音にも注意という規定です。［p.3 撮影①〜④］

連絡先の電話・メールは原PDFで参照できるため、このノートには転記していません。
