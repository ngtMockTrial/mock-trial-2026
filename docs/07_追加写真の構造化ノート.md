# 追加写真の構造化ノート

原本：S03 [写真ZIP](../00_元資料/Photos-1-001.zip)。12枚を元ファイル名のまま展開し、個別に目視確認しました。本ノートは内容の構造化・要約であり、逐語翻刻ではありません。題名・紙面番号が違う配布資料を一冊とみなさず、写真単位で管理します。

本ページの「本件での使い道」は今回追加した分析です。写真本文に本件についての結論が書いてあるわけではありません。写真の一般説明と、正式な号証・採否・実施ルールが異なる場合は、本件教材・ルールブックの該当記載を確認します。

## P01 尋問事項の検討にあたってのポイント

[原画像 IMG_4394.JPG](../00_元資料/追加写真/IMG_4394.JPG)／紙面1。

### 内容

- 尋問では評価より具体的事実を聞き、その評価は論告・弁論で行う。凶器、刺した部位、回数などの事実に分解する例がある。
- 論告・弁論で使いたい事実から、尋問の獲得目標を定める。想定回答を考え、聞き漏らしや追加質問に備える。
- 主尋問では時系列に沿って説明してもらうと伝わりやすい。反対尋問では、客観証拠との矛盾、変遷、不合理な説明等の確認や、自分側に有利な事情の獲得を考える。
- 時間内にすべてを聞こうとせず、争点への重要性で選ぶ。
- 主尋問の誘導は原則避けるとの説明。5W1Hを使う質問例を示す。反対尋問では誘導質問を使えるとの説明。
- 一問一答を心がけ、長い前置きや複数事項を一つの質問に詰めない。威嚇・侮辱、重複、意見を求める質問、直接経験していない事実への尋問に注意する。
- 書面提示の目的を説明し、必要に応じ裁判長の許可を得る。先に本人の説明を得てから書面を示す等、不当な誘導を避ける工夫が挙げられている。

### 本件での使い道

大滝に「見落としはあり得ないですね」と結論だけを求める前に、B地点をどの方向からどれくらい確認したかを聞く。木村には「説明が不自然ですね」という評価より、転倒・着用・紛失に関する実際の記憶を確認する。［Q01〜Q06］

## P02 尋問の手法

[原画像 IMG_4395.JPG](../00_元資料/追加写真/IMG_4395.JPG)。

### 内容

「尋問手続とは」「尋問の形式や注意事項」「主尋問の手法」「反対尋問の手法」の見出し。人から証言・供述を引き出す手続、一問一答という記載があり、目的、主尋問、反対尋問の目標・方法については広い記入欄が残っています。

### 本件での使い道

P01を参考に、自分たちの獲得目標を整理するワークシートとして使う。**空欄には資料由来の解答はありません。** 後で書き込む説明は、自分たちの検討案と明示します。

## P03 刑事裁判って何だろう？

[原画像 IMG_4397.JPG](../00_元資料/追加写真/IMG_4397.JPG)／紙面2。

### 内容

裁判を証拠で事実を確認し法律を適用する手続として説明。民事と刑事の当事者、裁判員裁判、自白事件と否認事件、冤罪、無罪推定、証拠と証明責任、有罪無罪と量刑の違いを扱っています。

### 本件での使い道・留意点

本件は犯人性を争う設定です。逮捕・起訴だけで有罪を前提にせず、証拠で何を示せるかを考えるために使います。資料には有罪率の数値や裁判員制度の一般説明もありますが、発行年・統計母集団等の裏付けはこの写真だけでは不明です。現在の統計や制度の正確な説明としてそのまま原稿に使いません。量刑の一般説明は、本件フォローアップの「求刑・量刑意見なし」と分けます。

## P04 裁判員裁判はどのようにすすむの？

[原画像 IMG_4398.JPG](../00_元資料/追加写真/IMG_4398.JPG)／紙面3。

### 内容

本人確認 → 起訴状朗読 → 黙秘権の説明 → 被告人の罪状認否 → 弁護人の意見 → 検察官・弁護人の冒頭陳述 → 証拠の確認 → 証人への質問 → 被告人への質問 → 検察官の最終意見 → 弁護人の最終意見 → 被告人の最終陳述 → 判決、という流れを図示しています。

### 本件での使い道

冒頭陳述が立証予定の説明、論告・弁論が証拠調べ後の評価という役割の違いを把握する。実際に参加する企画の順序・時間・省略手続はS02によります。

## P05 刑事裁判のルール

[原画像 IMG_4399.JPG](../00_元資料/追加写真/IMG_4399.JPG)。兵庫県弁護士会法教育委員会の表示があります。

### 内容

有罪の証明を検察官が行うこと、法廷に現れた証拠をもとに判断すること、常識に照らして有罪と確信できなければ有罪としないことを、三つの原則として説明しています。

### 本件での使い道

採否留保調書にだけある事情を、法廷で確認された事実のように原稿へ書かないための基準にする。「被告人が真犯人を示せない」ことを有罪理由にしない。

## P06 支援弁護第1回レジュメ・紙面1

[原画像 IMG_4400.JPG](../00_元資料/追加写真/IMG_4400.JPG)。

### 内容

事件発生から逮捕・勾留、起訴への流れ。冒頭手続として、人定質問、起訴状朗読、黙秘権告知、罪状認否を説明。証拠調べ手続の冒頭陳述では、検察官が証拠によって立証しようとする事実関係を明らかにすると説明しています。

### 本件での使い道

公訴事実・冒頭陳述を、それだけで認定に使える証拠と扱わない。身柄拘束と有罪認定を区別する。

## P07 同レジュメ・紙面2

[原画像 IMG_4401.JPG](../00_元資料/追加写真/IMG_4401.JPG)。

### 内容

- 書証・物証・人証という分類、取調請求、証拠意見、裁判所の採否を説明する。
- 証人尋問について、申請した側の主尋問、相手側の反対尋問を説明する。
- 被告人質問について、黙秘権などの点で証人と異なり、弁護人から検察官の順で質問する流れを説明する。
- **本件の甲3・乙2が不同意・採否留保であり、その内容を判断材料にするには大滝の証人尋問や被告人質問で取り上げる必要がある**という本件への注記がある。

### 本件での使い道・注意

甲3・乙2から獲得すべき供述を洗い出すための重要な説明資料。単に質問事項に触れただけで足りるとはせず、実際の回答を根拠として記録します。

本文中には検察側請求を甲号証、弁護側請求を乙号証とする簡略な説明があります。一方、教材p.2では乙1・乙2も検察官請求証拠です。本件の請求主体・採否は教材の証拠整理メモを基準にし、この一般説明で上書きしません。

## P08 同レジュメ・紙面3

[原画像 IMG_4402.JPG](../00_元資料/追加写真/IMG_4402.JPG)。

### 内容

論告・弁論を証拠に基づく最終意見として説明し、判決は証拠に基づき犯罪の有無や刑を判断するものと説明しています。

### 本件での使い道

最終意見では、単なるストーリーの再話より「どの証拠から、どんな事実・評価が導かれるか」を示す。量刑に関する一般記載を本企画の求刑許可と解釈しません。

## P09 証拠裁判主義・証明責任・無罪推定

[原画像 IMG_4403.JPG](../00_元資料/追加写真/IMG_4403.JPG)／紙面2、見出し「3 刑事手続きの流れ」。

### 内容

証拠裁判主義、検察官の証明責任、合理的な疑いが残る場合の無罪という原則を示します。検察官には有罪認定に必要な事実と証拠構造の把握、弁護人には構造の弱点や検察主張と矛盾する事実の検討を促しています。双方とも争点と検察官の証拠構造を捉えるよう求めています。

### 本件での使い道

[争点表](05_争点と双方の検討.md) を用いて、眼鏡・血液から刺突行為者の特定までの段階を比較する。有罪らしさの印象だけを積み重ねず、各段階の根拠を確認する。

## P10 刑事手続きの流れ

[原画像 IMG_4404.JPG](../00_元資料/追加写真/IMG_4404.JPG)。

### 内容

事件発生から捜査、場合によって逮捕・勾留・捜索・差押え、起訴、証拠開示・公判前整理、公判の冒頭手続、証拠調べ、論告・弁論、判決までを示す図。質問の役割と、採用された証拠を取り調べる点も示しています。

### 本件での使い道

捜査段階の資料と法廷で取り調べる証拠、準備と最終意見の役割を区別するための見取り図。資料中の主尋問・反対尋問の説明は理解のための簡略表現であり、反対尋問でも自己に有利な事実を得る役割があることはP01と合わせて読む。

## P11 事実認定の方法

[原画像 IMG_4405.JPG](../00_元資料/追加写真/IMG_4405.JPG)／紙面3。

### 内容

直接証拠型では、信用性が肯定されれば要証事実を直接認められる証拠を扱う例として、犯行・犯人の識別ができる映像や目撃供述を挙げています。間接事実型では、証拠から間接事実を認め、そこから推論を経て要証事実へ至ると説明。複数の間接事実を組み合わせる図を示しています。

### 本件での使い道

本件の映像は顔が判別できず、刺突場面そのものでもないため、P11にいう識別可能な犯行映像と同じには扱いません。眼鏡の鑑定から「本人の物」「被害者血液の付着」を整理し、そこから「本人が事件時に着用」「本人が刺突」と進む推論を分けます。

## P12 事実認定の演習

[原画像 IMG_4406.JPG](../00_元資料/追加写真/IMG_4406.JPG)。

### 内容

設例1はボールペンの所有、設例2は王子とシンデレラの好意について、それぞれ直接証拠と間接証拠・間接事実を考える設問です。解答欄は空欄です。

### 本件での使い道

証拠・そこから認める事実・その先の推論を分ける練習に使う。設問に対する独自の例を作る場合は「自作の演習例」と明示し、資料に解答が書かれているとしません。

## 写真から読み取れない情報

各資料の配布日・発行年・正式な資料全体名・前後の欠落ページは、写真だけで確定できません。P05以外も同じ発行主体とみなす根拠はありません。写真は撮影された解説資料であり、教材の証拠整理メモに新しい書証として登録されたものではありません。
