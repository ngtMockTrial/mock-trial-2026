## 立証の中心を眼鏡に置く

検察の中心命題は、**木村の眼鏡と被害者の血液が現場で結び付いている事情を、事件時の木村の接近・刺突行為へ結び付けること**。動機や服装から先に犯人を決めない。現段階では、事件時の着用・血液付着・落下の順序に未確認部分があり、有罪を立証し終えたとは扱えない。［推論方針：R02・T01、甲1 p.3〜6］

| 段階 | 検察が示す内容 | 根拠と残る課題 |
|---|---|---|
| 証拠 | 現場で発見された眼鏡を木村が自身の遺失物と認めた。指紋・皮膚片も木村と一致し、血痕は被害者のDNA型と一致する | 資料記載：甲1 p.3〜4・6。E02・E03→F01・F02。所有の裏付けを複数の独立した犯行証拠と数えない |
| 間接事実 | 木村と結び付く私物が、被害者血液を伴って事件現場に残された | 推論：R02。単なる所有物の紛失より事件との関係を検討する理由がある。ただし、鑑定は付着時刻・着用者を示さない |
| 橋渡し | 事件時に木村が眼鏡を着用して近接し、刺突の場面で残したという説明 | 仮説：R01・R02。清掃時の不在、紛失の記憶、他の材料を比較する必要がある。清掃後にBへ来たことと木村が直接落としたことは別 |
| 要証事実 | 木村が刺突行為者である | 立証目標：T01。在場から行為への推論を省略せず、自転車・動機が何を補うかを示す |

自転車にも被害者のDNA型と一致する血痕があり、木村はその自転車を通常使うと供述している。眼鏡以外にも木村の利用物と被害者が結び付く点は補助になる。しかし共用・無施錠・外部から出入り可能で、血液付着時の使用者は特定できていない。映像との同一性も未確定なので「この自転車で逃げた」と一括しない。［資料記載・推論：甲1 p.4〜5、乙1 p.25、R03・R04／D04・D05］

12月24日のメッセージは、岸井を名指す怒りと、近所の駐車場で見るという認識を示す。物証から検討する説明に、対象と場所の認識を補う順番で使う。殺害計画や当日の来訪を記録したものではない。［資料記載・推論：甲2 p.19、R05／D06］

## 弁護の強い反論にどう答えるか

以下は応答の骨子であり、完成原稿ではない。相手の反論を弱く言い換えず、争いが残る箇所を明確にする。

| 弁護の反論 | 検察の応答方針 | 応答後も残る限界 |
|---|---|---|
| 昼に失くした眼鏡へ後から血液が付いた可能性がある | それが確認済みの経過なのか、推測なのかを区別する。現場の私物と被害者血液の組合せを出発点に、清掃の具体的証言が得られた場合だけ時間幅を絞る | 昼の紛失の裏付けが弱くても、検察の事件時着用が証明されるわけではない。D02・D03、甲1 p.3〜4・6、乙2 p.28〜29は留保 |
| 急いだ清掃では眼鏡を見落とし得る | 当日Bを見た位置・経路・地面の見え方が得られれば、その具体性を示す。急いだという一語だけで観察の価値が消えるわけではない | Bの具体的観察を獲得できなければ「必ず見つけたはず」を使わない。D01、甲3 p.21〜22は留保 |
| 自転車は他人も使え、映像の顔も分からない | 共用を認めた上で、木村の私物と通常利用物の双方に被害者との接点があることを比較材料とする | 二つの付着経緯や事件時利用者は未確定。映像を木村と決めて自転車を特定し、その自転車から映像を木村と決める循環を避ける。D04・D05、甲1 p.4〜5、乙1 p.25 |
| 怒っていたことは殺人を意味しない | そのとおりであり、怒りは実行を直接示すものではない。岸井という対象・駐車場の認識が物証に基づく説明へ何を追加するかを述べる | 過去の暴力歴を犯人性の不足の穴埋めにしない。D06、甲2 p.18〜19 |
| 仮に現場にいたとしても刺したとは限らない | 最も重要な反論として受け止める。眼鏡・血液・利用物・動機を合わせた説明が、単なる在場を超える理由を人が検討する | 現時点でこの橋渡しは未確定。「他の犯人を言えないから木村」としない。T01・D09 |

## 清掃の前提を外して比較する

**清掃証言を使えない場合**：眼鏡の所有・血痕、共用自転車の血痕・通常利用、LINEは残る。しかし眼鏡がBへ来た時間幅は絞れず、事件時着用の説明は弱くなる。昼の紛失や後の移動・付着を排除済みにしない。［推論：甲1 p.3〜6、甲2 p.19、乙1 p.25、D08・D09］

**当日Bの具体的観察が得られた場合**：清掃時にBに眼鏡がなかったとの推認を検討できる。これが支えるのは清掃後のBへの到達であり、20時30分の直接落下ではない。弁護の「昼からBにあった」という説明への反論と、道路から後で移ったという別の仮説への反論を分ける。［条件付き推論：R01・R02／D01・D02、準備根拠：甲3 p.22］

**映像を外した場合**：私物・血液の中心部分は残る。顔を特定できない映像を強く言うことに時間を使わず、犯人性の橋渡しを説明する。**動機を外した場合**も物証は残るが、岸井に接近する理由の補助が弱くなる。どちらも、残った材料だけで結論へ進めるかを別に評価する。［推論：R02〜R05／D05・D06・D08］

## 当日の20分で行う修正

準備段階で印刷・端末へ保存し、試合中は外部通信によるAI支援を使わず、出場メンバー内で次を行う。［ルールブックp.2〜3］

1. **0〜5分**：実際の回答を、発言者・問い・回答内容・記録箇所とともに整理する。予定回答と違った所を先に抽出する。
2. **5〜10分**：清掃の具体的観察、紛失の記憶、事件日の行動について、どの前提まで使えるかを決める。甲3・乙2全体を採用済みに変更しない。
3. **10〜15分**：上の12分構成の該当段落を修正する。相手の最も強い反論への応答を確認し、回答から言えない断定を削る。
4. **15〜20分**：根拠の号証・ページ、実際の供述との対応、持ち時間を確認する。読み合わせで時間超過なら、補助的な映像・動機の説明から短くし、眼鏡と反論への応答を優先する。
