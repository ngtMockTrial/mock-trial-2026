## IDの使い分け

| ID | 対象 |
|---|---|
| S01〜S03 | 元PDF・写真ZIP |
| P01〜P12 | ZIP内の解説写真。事件の証拠番号ではない |
| E01〜E10 | 今回の証拠分析単位。教材の正式号証とは別 |
| I01〜I08 | 争点・検討事項 |
| Q01〜Q10 | 追加で確認する質問 |

既存テキストにあるE1等とは別体系です。今回の文書では先頭ゼロ付きのE01等を用います。甲1の複数の記載を分析のために分けたIDであり、証拠数や独立性を増やすものではありません。
