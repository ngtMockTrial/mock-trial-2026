# 検討の仕組みの評価と深め方

2026-10-22。共同編集に向けた運用評価。事件の新たな証拠評価・人のレビュー・完成原稿ではない。

## 判断

**現在の仕組みを維持し、検討と共同編集の手順を補強する。** 正本をMarkdownに置き、E→F→R→T、反論D、確認Q、準備・将来候補を分ける構成は、双方の弁論を深める土台として適切。採否と人のレビューが別で、原資料へ戻れ、原稿化ゲートが未確認依存を残す点もよい。図の作り直しや新しい評価点数は不要。

限界は、グラフの整合性から推論の妥当性は判定できないこと。同じ命題にAIの説明を追記し続けても、反論が検証されたり、独立した裏付けが増えたりするわけではない。T00は検察側の立証目標であり、検討開始時の答えではない。弁護はD09を入口に検察の推論を問い、別の真犯人の立証を目標にしない。

## 一回の検討を小さく、比較可能にする

一回につき一つの橋渡しを選ぶ。正本の既存「根拠・前提」「反論への応答」内に、次の項目を短く追記する。新しい必須属性や別の正本は増やさない。

| 項目 | 記録する内容 |
|---|---|
| 今回問う命題 | 誰のどの行為・時刻・同一性を、どこまで言いたいか |
| 確認できる出発点 | 号証・教材p.、必要なら実画像。資料記載と認定の可否を分ける |
| 推論の橋渡し | 出発点から結論へ進むために必要な条件 |
| 検察の最も強い説明 | 相手に不利な事情も含めて、なぜ結び付くと考えるか |
| 弁護の最も強い反論 | 資料に即した疑問。単に想像できる筋と区別する |
| 前提を外した比較 | 一つの前提が使えないとき、残る資料からどこまで言えるか |
| 何が分かれば変わるか | 具体的な質問・記録の該当箇所と、異なる回答時の扱い |
| 残る限界 | 言える最小範囲、未確認点、双方がなお説明できない部分 |

「前提を外す」は比較上の仮定であり、正本のinputsを一時的に削除して試さない。関係を実際に変更するときは本文と属性を同時に修正し、変更理由を残す。

## 既存の検討に適用する順序

これは[双方の検討](13_双方の立証構造と評価.md)・[裁判官視点](15_裁判官視点と判決の分岐.md)の読み方で、新しい事件事実を追加しない。事件の記載・号証・教材ページはリンク先の正本で確認する。

| 対象 | 深める問い | 戻る正本 |
|---|---|---|
| 清掃→到達時期 | 当日の観察・発見可能性のどちらが欠けると、何を言えなくなるか。清掃供述を使わない比較でも犯人性を論じられるか | [R01](../検討/ノート/R01.md)、[D01](../検討/ノート/D01.md) |
| 眼鏡→在場・行為 | 所有、事件時の着用、血液の付着時期、刺突行為をどこで区別しているか | [R02](../検討/ノート/R02.md)、[D03](../検討/ノート/D03.md) |
| 自転車・映像 | 各枝は独自に何を加えるか。同じ本人特定の仮定を互いの裏付けにしていないか | [R03](../検討/ノート/R03.md)、[R04](../検討/ノート/R04.md)、[D04](../検討/ノート/D04.md)、[D05](../検討/ノート/D05.md) |
| 総合評価 | 単独では弱い事情を組み合わせる理由を説明できるか。共通の未確認前提と同じ情報源を重複計上していないか | [T01](../検討/ノート/T01.md)、[D09](../検討/ノート/D09.md) |

尋問への接続は[既存の17項目](14_尋問の優先順位と回答分岐.md)を使う。必要な追加質問は、何を確認するためかを先に書き、想定回答と実際の回答を分ける。反対の回答でも直ちに結論を決めず、どの前提が変わったかを記録する。

## 原稿へ移す条件

各段落について「主張／根拠ノートID／利用できる資料／推論の橋渡し／最も強い反論への応答／残る条件」を対応付け、人が確認する。AI案の追加、PRのマージ、CI成功をreviewの「採用」に読み替えない。

原稿化ゲートは未確認・未レビュー等を拾う補助。通過しても、証明の十分性、証言の信用性、反論の実質的な解消を保証しない。主争点T01と補助のT02・T03を区別し、実施ルールの各12分・求刑量刑意見なしに合わせる。試合中の外部通信支援は行わない。
