## 知識として使う手順

1. 人物・物・時刻の語で本書か年表のK番号を探す。回答の言い回しが必要ならS04のページ・問番号まで戻る。
2. その行の区分を保ったまま使う。「木村は外出していないと回答した」を「外出しなかったと認定済み」に変換しない。
3. 甲3・乙2の未採用内容は、S04で同じ内容を実際に述べた範囲だけE11・E12経由で参照する。書証と後の回答を混ぜない。
4. 推論や別の説明を述べるときは、それを支えるK番号と未確認U番号を添える。記録がない部分には「不明」「未確認」と答える。
5. AIへ引き継ぐ場合は、まず本書・年表・構造化知識を読み、必要な原本・正本へ進ませる。これは参照可能な知識ファイルの整備であり、モデルへの追加学習や永続記憶の保証ではない。

JSONには資料IDと原本ハッシュ、人物・物の索引、年表64項目の区分・根拠・限界、U01〜U10を収録する。`schema_version`と`updated_on`を確認する。Markdown年表・本索引が人の編集用の内容であり、JSONを変更しただけでは正本の支持関係やreviewは変わらない。年表・索引変更時はJSONも照合して更新する。
