# 全体関係図の共有用エクスポート

2026-10-21。ユーザーの「今のObsidianのグラフビューをもとに、みんなに見せる全体の関係図をエキスポートして」という依頼で作成した。

- [共有・拡大閲覧用PDF](../output/共有用/模擬裁判_全体関係図_20261021.pdf)
- [画像として送るPNG](../output/共有用/模擬裁判_全体関係図_20261021.png)
- [書出し記録・座標・関係・正本ハッシュ](../output/共有用/全体関係図_書出し記録.json)

標準グラフの本筋34項目・41接続を、CLIで取得したライブ座標から書き出した。現在の版は中心力約0.4に調整後の詳細43項目の表示を取得し、準備・確認9項目を除いて本筋34項目を表示している。点の相対位置、立場色、表示重要度、矢印方向を保持し、白背景、全文ラベル、利用状態、線の凡例を付けた。ラベルの配置だけを共有用に調整し、Obsidianの座標へは書き戻さない。元のグラフ画面そのもののスクリーンショットとは異なる。

青＝検察、赤＝弁護、灰＝双方共通。実線＝支持、破線＝反論、点線＝条件付き支持。細い引出線はラベルと点の対応で、命題同士の接続ではない。採用済み資料は緑の文字、未確認前提への依存は黄の文字で示す。T00の文言は最終立証目標・未認定であり、有罪認定を示すものではない。

準備・確認9項目は通常グラフと同じく省略した。採否留保、未獲得供述、未確認依存は解除しない。出典・判断理由の正本は各IDの `検討/ノート/ID.md`。図の文言は既存の命題・状態から転記しており、新たな事実認定や人のレビューを追加していない。

## 再現と確認

編集用データは[ライブ座標](../作成用/構造化確認/共有図_ライブ座標_20261021.json)、生成処理は[export_shared_graph.py](../作成用/export_shared_graph.py)。`python 作成用/export_shared_graph.py` で、この取得時点の配置を再現する。正本は実行時のものを読むため、内容を更新した後はその時点の新しい書出しになる。通常の「検討を更新.cmd」からは自動再生成しない。

Pythonのreportlab・Pillow・PyMuPDF・PyYAMLを使う。reportlabが通常環境にない場合は、このPCのCodex同梱依存先を参照する。

ライブグラフと正本の41接続の向き・集合の一致、IDの一意性、34項目のラベル同士の非重複を確認。PDFをPNGにレンダリングして実画像を確認した。正本43ノートの内容ハッシュが書出し前後で一致することも確認した。原資料・Canvas・人のレビュー・グラフ設定は編集していない。
