# 論証をたどる — 表示の設計

2026-10-24。Obsidianの正本をブラウザで読むための、読取専用の共有画面。

左の検索・一覧→中央の関係グラフ→右の本文という順序を使う。グラフは暗い背景で接続を見渡し、長文は白い背景で読む。検察の青・弁護の赤・共通の灰と、留保等の黄は既存の意味を維持する。T00を最大にするが、証明済みや証拠力を示すサイズにはしない。

実行時のトークンは`styles.css`の`:root`。背景・本文・補助文・境界・立場色・警告・フォーカス・文字サイズを集約する。図の点は暗い背景に合わせた明るい同系色。種類・立場・状態は本文にも文字で示し、色だけに頼らない。

グラフは正本の関係だけを使うD3の力学配置。ObsidianのピンやCanvas座標は変更しない。初期表示・ドラッグ解放・設定変更後は最低3秒間ソルバーの温度を維持し、その後冷却して収束させる。操作がなければ最大8秒で停止する。手動停止・非表示タブ・ページ離脱では直ちに止める。動きを減らす設定でも同じ時間計算を続け、アニメーション描画を省いて終了時に結果を描く。拡縮・画面に収める・配置の停止／再開ボタンも置く。右上は力・表示の調整だけとし、全体／周辺の切替は置かない。

本文で表示中のノートと、グラフで明示的に強調したノートを分離する。初期表示は全体を明るくし、ホバー／フォーカスの間とクリック選択後だけ関係外を暗くする。未選択時のホバー解除では全体表示へ戻る。背景クリック・Escape・画面に収めるでも強調を解除する。初期URLのノート指定や本文の既定ノートだけで全体を暗くしない。

共有設定は`graph-settings.json`の保存済みObsidian設定。力はD3向けに換算し、サイズ・線幅・矢印・色グループ・文字のしきい値を表示へ反映する。ブラウザの調整は共有設定ハッシュごとのlocalStorageに置く。新しい共有設定が配信されれば、その共有値を新しい初期値とする。D3の配布ファイルとライセンスは`vendor/`に固定し、CDNを使わない。公式Obsidianのエンジンや画面の完全複製ではない。

850px以下では本文をグラフの下へ、560px以下では検索一覧・グラフ・本文を縦に再配置する。本文の表は横スクロール、日本語の長い命題は折り返す。選択IDをURLのhash、表示範囲・検索・立場をqueryに保持する。表示範囲を省略しても利用状態や未確認依存は解除しない。

本文はPython-Markdownで変換した後にタグとリンクを制限する。外部スクリプト・CDN・外部フォントを使わず、原資料リンクは公開ビルド内のコピーを開く。Pagesからレビューや原資料を書き換える操作は設けない。
